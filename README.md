Scale-matched comparable-launch forecast of GTA VI's launch-day Twitch viewers: it reads the hour-1 print and the case's comparable launches, then writes quantile forecasts for hours 2 to 24.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
